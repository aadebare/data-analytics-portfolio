# Project 5 — GoldCare Connect Analytics Dashboard (Capstone)

### Overview
End-to-end capstone project combining CQC, NHS and Skills for Care data 
to identify GoldCare Connect's national market opportunity.

### View Interactive Dashboard
[Click here to view on Tableau Public](https://public.tableau.com/app/profile/adebowale.adebare/viz/GoldCareConnectNationalMarketAnalyticsDashboard/GoldCareConnectAnalytics?publish=yes)

### Tools Used
- Python (Pandas) — Data integration and preparation
- MySQL — Business analysis (CTEs, Window Functions)
- Tableau Public — Interactive dashboard

### Data Sources
| Source | Used For |
|---|---|
| CQC Care Directory (Aug 2026) | Care home counts and ratings |
| NHS Digital Workforce Statistics (May 2026) | NHS leavers by region |
| Skills for Care Statistical Appendix (2024/25) | Turnover and vacancy rates |

### Key Findings
- London has the highest Crisis Score (32.7) — most urgent market
- South East is #1 expansion priority (Score: 93.6)
- National saving potential of £102.4M annually
- 292% ROI in Year 1 for every adopting care home
- South East faces greatest workforce pressure — 72,187 annual leavers
