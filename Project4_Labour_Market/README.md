# Project 4 — UK Labour Market Post-Pandemic
## Interactive Tableau Dashboard

### Overview
Analysis of UK labour market trends from 2000-2026 using ONS official 
statistics. Focuses on the post-pandemic recovery and whether the UK 
has returned to pre-pandemic employment levels.

### View Interactive Dashboard
[Click here to view on Tableau Public](https://public.tableau.com/app/profile/adebowale.adebare/viz/UK_Labour_Market_Post_Pandemic_Analysis/Dashboard1?publish=yes)

### Tools Used
- Python (Pandas) — Data loading and cleaning
- Tableau Public — Interactive dashboard

### Data Source
ONS Labour Market Statistics A01 (September 2026)
ons.gov.uk

### Key Findings
- Employment rate not fully recovered (75.1% vs 75.9% pre-pandemic)
- Unemployment remains elevated (4.9% vs 4.1% pre-pandemic)
- COVID caused sharp but short unemployment spike in 2020
- Labour market broadly stable but structural changes persist
